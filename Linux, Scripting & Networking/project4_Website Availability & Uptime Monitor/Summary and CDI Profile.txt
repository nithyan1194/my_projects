Summary: Automated Endpoint Availability & Health Monitor
Context: Microservice integrations and external HTTP dependencies lacked real-time edge health probes,
making it difficult to differentiate between backend service crashes and network timeouts during early incident stages.
The constraint was to construct a lightweight, configurable availability probe that tracks HTTP response codes and network
latency without installing external agent daemons or heavy monitoring stacks.

Decision: Selected POSIX-compliant Bash utilizing native curl metric-formatting flags (-w "%{http_code} %{time_total}")
fed into stream loops. Explicitly chose not to use Python or NodeJS runtime frameworks to keep host resource utilization 
minimal and run cleanly on restricted bastion hosts or minimal container images.

Impact:

Instant Health Diagnostics: Reduced endpoint triage time from minutes to a <1 second execution sweep across all defined service routes.

Sub-Second Precision: Captured network response latency with millisecond-level accuracy, establishing baseline response trends before SLA degradation occurs.

0 MB Memory Footprint: Delivered zero-daemon monitoring capability with zero background RAM consumption.
